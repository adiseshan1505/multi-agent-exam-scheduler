    Environment classification

    ObservablePartially. The Coordinator only knows a resource's state by querying it or hearing a broadcast. Its beliefs can be stale, so a booking can still be refused.
    DeterministicStochastic. Resources may refuse bookings unexpectedly (flakiness), and sickness or maintenance arrive at random.
    EpisodicSequential. Every booking constrains all later ones.
    StaticDynamic. Availability changes while the Coordinator is still scheduling.
    DiscreteDiscrete. Hour-granular slots and a finite set of rooms and invigilators.
    AgentsMulti-agent. Cooperative overall. Exam agents compete for slots and priority breaks ties.

    Algorithm

    A CSP solved with backtracking search. Heuristics: MRV (most-constrained exam first), degree and priority as tie-breakers, preference-first and best-fit-room value ordering, and forward checking. Committed exams stay fixed, so a replan only searches the affected exams. If the search fails, a priority-ordered fallback places what it can and the Coordinator negotiates with the rest.
